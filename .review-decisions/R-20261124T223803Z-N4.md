## `README.md:5359` — the README names two of the three signals that restore the terminal of `faulte tui`

**Settled** 2026-11-24 (branch issue-669, finding R-20261124T223803Z#N4)

The finding is accurate. The README says "A quit, a panic, `SIGTERM`, and
`SIGHUP` each restore the terminal." `LEAVING_SIGNALS`
(`src/faulte/src/main.rs:92`) is `[SIGTERM, SIGHUP, SIGINT]`, thus a
`kill -INT` also leaves through the flag and restores the terminal. The PR
body names all three signals. Ctrl-C in raw mode is a key, not `SIGINT`, and
the key table covers it.

The omission makes no statement false. A person who sends `SIGINT` gets a
restored terminal, which is the result that the README promises for the
other two signals.

The fix is one word of prose in the README. The round that found it was
record-only, and changed text is new text that the next review must read.
That review starts one more round, and the round costs more than a missing
name of a signal that behaves as the README leads a person to expect.

The boundary: this settles the omission of `SIGINT` from this sentence. A
signal that the README names and that does not restore the terminal is a new
finding.
