## `src/nle/src/ui/timeline.rs` `TimelineView` — the doc gives only the horizontal wheel

**Settled** 2026-11-27 (branch issue-150, finding R-20261127T163409Z#N2)

The finding is accurate. The doc of `TimelineView` says that "a horizontal
wheel scrolls". Commits dda7a9f0 and 852809af changed the rule of
`crate::timeline::wheel_action`. A mostly horizontal delta scrolls. With Shift,
a mostly vertical delta scrolls. A mostly vertical delta with no modifier keeps
its default action. The doc does not give the Shift rule or the word "mostly".

The doc is incomplete, not wrong. A horizontal wheel does scroll. The same
sentence points to `crate::timeline::wheel_action`, and the doc of that
function states the full rule. The README paragraph of the timeline states it
for a person.

**The fix costs more than the defect.** The fix is prose in a doc comment. It
changes no behavior, and a fresh review must read it. The loop then starts one
more fix round for a summary that its own link already completes.

**The boundary.** This record settles only the omission of the Shift rule and
of the word "mostly" from the doc of `TimelineView`. These occurrences reopen
it:

- a change that removes the link to `crate::timeline::wheel_action` from the
  doc
- a change that makes the doc say something false, for example that a vertical
  wheel with no modifier scrolls, or that Shift does nothing
- a change to the rule of `wheel_action` that makes "a horizontal wheel
  scrolls" false
