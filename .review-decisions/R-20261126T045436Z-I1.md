## `src/ufa/src/config.rs` — more non-blocking hardening of the save path of the config file is out of scope for this branch

**Settled** 2026-11-26 (branch ufa, finding R-20261126T045436Z#I1)

More non-blocking hardening of the symbolic-link case, the dangling-link
case, and the permission-window case of the save path of the config file is
out of scope for this branch. The save path is `replace_config_file`,
`end_of_link_chain`, and `create_config_file`. Commit `ba527d2ae` removed
`create_config_file`, and `replace_config_file` now does its job: it makes
the new file at mode `0600`. Thus a finding about the mode of a new config
file is a finding about `replace_config_file`.

Three fix rounds in a row on this path each found a new edge case. Each fix
added code and tests, and the next review found an edge case in that new
code. The code grows faster than the review closes it. The finding that
this record names got its test (a chain of two links across directories),
and the code was already correct.

The boundary:

- **Settled:** a non-blocking finding that asks for more hardening of these
  three cases on this path. Examples are one more shape of a chain of links,
  one more state of a dangling link, or one more window in which the mode of
  a file is wider than `0600`.
- **Not settled, still in scope:** a correctness defect that loses data, a
  defect that writes the keys to a file that a different user can read, and
  each blocking finding. A finding of one of these kinds reopens the path.
