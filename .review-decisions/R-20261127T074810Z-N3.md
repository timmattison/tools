## `termstate::ColorSource` — the docs of `Indexed` and `Rgb` name only the semicolon form

**Settled** 2026-11-27 (branch issue-165, finding R-20261127T074810Z#N3)

The finding is accurate. Commit `e92391f70` added the colon form of an extended
color. `38:5:n` and `48:5:n` now give `ColorSource::Indexed`, and `38:2:r:g:b`
and `38:2:cs:r:g:b` now give `ColorSource::Rgb`. The docs of the two variants
still name only `38;5;n`, `48;5;n`, `38;2;r;g;b` and `48;2;r;g;b`.

The defect is in prose only. The variants are correct for both forms. The doc of
`read_colon_color` names each colon form, and the tests of the colon form hold
the source of each color.

**The fix costs more than the defect in this round.** The fix is prose. This
round of the review loop is record-only. A change is a diff that a review must
read, and that review can find a new nit in it. Then one more fix round starts.

**The boundary.** This record settles only the docs of `ColorSource::Indexed`
and `ColorSource::Rgb` for the colon form. Each of these occurrences reopens it:

- a doc that names a form that does not give that variant
- a new form of an extended color that gives one of the two variants
