## `src/msgs/frontend/src/export.ts` — an Escape in the search box also cancels the export selection (second report)

**Settled** 2026-11-25 (branch msgs, finding R-20261125T194029Z#N2)

This finding repeats R-20261125T184504Z#N1, and it is accurate.
`.review-decisions/R-20261125T184504Z-N1.md` gives the decision, the cost, and
the boundary. This record answers the one new argument.

The new argument is commit 5603b659a, which made the conversation keys act only
outside controls. That commit does not set a rule for this listener. In a text
input, an arrow key moves the caret, thus a conversation key in the search box
did two different things. An Escape in the search box does two cancels, and the
only loss is the start message of the selection.

The cost of a fix is the same: new code and a new test in `search.ts` or
`export.ts`, and one more review round, to save two clicks.
