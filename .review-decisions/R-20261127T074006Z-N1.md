**Settled** 2026-11-27 (branch issue-161, finding R-20261127T074006Z#N1)

The finding is correct. No test runs the `(true, false)` arm of the match in
`restore`, and neither `assert_same_screen` nor `assert_viewer_is_reference`
compares `uses_line_drawing`. Thus a mutant that changes that arm to `""`
passes each test.

The arm is correct as written. It selects line drawing when this state uses
line drawing and `from` does not. It is the mirror of the `(false, true)`
arm, which a test runs. The fix is a new paint test and a change to a shared
test helper. This round of the review loop is record-only. A change to the
helper changes what each paint test asserts, and the review of that change
can start more than one new fix round.

Boundary: a report of a wrong character set after a restore reopens this
decision. A change to `restore` reopens it too.
