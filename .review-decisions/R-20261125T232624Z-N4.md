## PR #766 body — the summary sentence "the same regions and the same text as before" stays

**Settled** 2026-11-25 (branch issue-761, finding R-20261125T232624Z#N4)

The finding is accurate. The Recorded row of the properties panel changed its
format. The React code wrote `toLocaleString()`, for example
`11/14/2023, 5:13:20 PM`. `format_recorded` writes `%Y-%m-%d %H:%M:%S`, for
example `2023-11-14 17:13:20`. Also, `format_duration` gives `0m 0.0s` for a
value below zero, where the TypeScript gave a negative text. Thus the summary
sentence of the PR body overstates the match.

The same body states both changes in its list of changes. The `format_duration`
item says that a value below zero gives `0m 0.0s`. The `format_recorded` item
gives the format `%Y-%m-%d %H:%M:%S`. Thus a reader of the whole body gets the
correct facts.

The cost of a fix: an edit of the PR body is a change to a document that the
review reads. It starts one more review round for one sentence, which can find
a new nit in the new text.

The boundary: a report that the summary sentence of the PR body overstates the
match is this decision. These changes reopen it:

- The PR body loses the `format_duration` item or the `format_recorded` item.
- A different visible text of the window changes, and the PR body does not
  state that change.
