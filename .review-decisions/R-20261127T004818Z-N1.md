## `src/nle/src/ui.rs` — a successful export clears a speed failure that came during the export

**Settled** 2026-11-26 (branch issue-158, finding R-20261127T004818Z#N1)

The finding is accurate. `App` has one error banner. The export bar and the
speed panel both write it through `error.set(result.err())`, thus each
success clears it. `busy` disables only Open Recording and Export, thus
Apply Speed stays enabled while the export renders. If an Apply Speed fails
during that render, the banner shows the speed failure. When the export
ends with success, the banner goes away.

The loss is small:

- The banner shows the failure at the time of the click on Apply Speed,
  because the speed panel reports its outcome in the same handler. The user
  sees the banner before the export ends.
- A failed Apply Speed changes nothing. The project keeps its filters, and
  the list of speed rows below the button gets no new row.
- No file is written, changed, or lost because of it. `Editor::export`
  clones the project when the render starts, thus an Apply Speed during the
  render does not change the exported file.

The cost of a fix: a source for the banner, kept with its text, or a change
of when the export clears the banner. The fix also needs a new window test
that holds an export pending, applies a bad speed, ends the export, and
reads the `role="alert"` element. That fix is new code in the view, and it
starts one more review round, which can find a new nit in the new code.

The boundary: a report that a success of one control clears a failure of a
different control is this decision. These changes reopen it:

- A failed Apply Speed or Remove changes the project, or a failure gets no
  banner at the time of the click.
- A success clears a failure of the same control before the user can read
  it, for example an export failure that a later step of the same export
  clears.
- A new control that runs work in the background, for example a second
  export or a background load, writes the same banner.
- A user reports a speed edit that they thought was applied and was not.
