## `src/repo-guards/tests/pre_commit_hook.rs` — the doc comment of `install_fake_cargo` names the hook as the file that holds the `cargo-machete` branch

**Settled** 2026-11-25 (branch github-actions-ci, finding R-20261125T220516Z#N1)

The finding is accurate. Commit 3d955735a moved the install branch of
`cargo-machete` from `.husky/pre-commit` into `scripts/rust-checks.sh`. The doc
comment of `install_fake_cargo` came from `main`, and it still says "the
`cargo-machete` branch of the hook".

**The comment still gives the correct reason.** The hook starts
`scripts/rust-checks.sh`, thus a run of the hook still gets to the install
branch. The fake `cargo` exits zero for `cargo install`, thus that branch cannot
reach the network. Only the name of the file that holds the branch is old.

**The cost of the fix is a new review cycle.** This round of the review loop is
record-only. A change of one phrase is new text that a fresh review must read,
and a fresh review can find a new nit in it. Then a new fix round starts, and
the loop does not end clean. The defect is one phrase in a test comment, and no
code reads it.

**The boundary.** This decision settles only the file name in this doc comment.
A fake `cargo` that lets `cargo install` reach the network, or a hook test that
runs a real `cargo install`, is a new finding.
