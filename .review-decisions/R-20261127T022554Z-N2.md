## `src/nle/assets/main.css` `.terminal-row` — the row height `1.2em` is a second copy of the line height of `.terminal`

**Settled** 2026-11-26 (branch issue-151, finding R-20261127T022554Z#N2)

The finding is accurate. `.terminal` states `line-height: 1.2`, the comment
above its `font-size` states 1.2em, and `.terminal-row` states `height: 1.2em`.
The test `the_style_sheet_fits_the_grid_to_the_pane` in `src/nle/src/ui/tests.rs`
ties the `font-size` formula to the line height, but not the row height. Thus a
change of the line height in `.terminal` and in the formula passes the test,
but after that change the grid does not fit the pane.

Today the three values agree, and the grid fits the pane. The defect is a
possible drift in a later change, not a wrong value now.

**The fix costs more than the defect in this round.** Each fix (`height: 1lh`,
a custom property that both rules read, or a new assertion in the test) is a
change of the style sheet or of a test. This round of the review loop is
record-only. That change is a diff that a review must read, and that review can
find a new nit in it. Then one more fix round starts.

**The boundary.** This record settles only the copy of 1.2 in `.terminal-row`
and in the comment. Each of these occurrences reopens it:

- a change of the line height of `.terminal` that does not change the row
  height
- a third rule of the style sheet that writes the line height as a literal
