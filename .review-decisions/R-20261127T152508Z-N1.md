coordinates, the z that keeps its cell is column 33, and column 34 changes
from z to y. The comment says "column 34", which is the 1-based column of the
CSI cursor position.

The fix is prose in one comment. This round of the review loop is record-only.
A change to the comment is new text that a review must read, and that review
can start a new fix round. The test does not use the number. Its three
assertions fix the cells, and they pass. The decision of
R-20261127T143505Z#N1 gives the same cost.

Boundary: this decision covers the column number in the comment only. An
