## `CLAUDE.md` — "run `./scripts/rust-checks.sh` from any directory" gives a path that resolves only from the root

**Settled** 2026-11-25 (branch github-actions-ci, finding R-20261125T121212Z#N2)

The finding is accurate. The section "Continuous Integration" of `CLAUDE.md`
says to run `./scripts/rust-checks.sh` from any directory. The relative path
resolves only from the repository root. The claim about the script is
correct: when a person starts it by a path that resolves, it changes to the
root of its own repository, and it runs the same checks from each directory.

**The cost is a new review cycle.** This round of the review loop is
record-only. A change to the sentence is a new change that a review must
read, and a fresh review can find a new nit in it. Then a new fix round
starts, and the loop does not end clean. The defect is in the wording of one
sentence. A reader in a subdirectory who types the path as written gets "no
such file", which names the cause at once. No check runs on wrong data, and
no check is skipped without a message.

**The boundary.** This decision settles only the wording of that sentence. A
`scripts/rust-checks.sh` that runs different checks, or fails, when a person
starts it from a directory other than the root is a new finding.
