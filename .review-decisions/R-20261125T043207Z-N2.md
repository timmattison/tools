## `src/workit/src/main.rs` — `member_paths` turns a backslash in a directory name into a slash on each platform

**Settled** 2026-11-25 (branch workit, finding R-20261125T043207Z#N2)

The finding is accurate. `member_paths` replaces each backslash of a member
with a slash on each platform. On macOS and Linux, a backslash is a legal
character of a directory name. On 2026-11-25, macOS kept a directory named
`c\d`. A package in that directory becomes the member `c/d`, which names a
directory that does not exist. The name is valid UTF-8, thus
`.review-decisions/R-20261124T182455Z-N2.md` does not cover it.

It is not fixed, because the fix costs more than the defect:

- **The name is rare.** The defect needs a package directory whose name holds
  a backslash, on macOS or Linux. A shell needs quotes to make such a name.
- **The failure is loud at the next step.** Cargo cannot load a member that
  does not exist. Thus the first `cargo build` or `cargo metadata` of the
  workspace stops with an error that names the member. No build uses the wrong
  package.
- **The cost is a new review cycle.** This round of the review loop is
  record-only. A fix and its test are new code that a review must read, and a
  fresh review can find a new nit in it. The review marked this finding as a
  nit, and at the stall (decision H-742-2 on issue #742), Tim chose to settle
  each nit with a record.

**The boundary.** This decision settles a backslash in the name of a package
directory on macOS and Linux. A different change that `member_paths` makes to
a path that is UTF-8, for example a lost component, is a new finding. A report
of this defect on a real tree reopens this decision.
