## `src/ufa/src/pagination.rs` — the module doc gives 25 as the default page size of each list endpoint

**Settled** 2026-11-27 (branch ufa, finding R-20261127T043105Z#N2)

The finding is correct. `integration.json` gives `limit` a default of 25 for
three list endpoints, and a default of 100 for
`/v1/sites/{siteId}/hotspot/vouchers`. The module doc says 25 for each.

The number is an example of why a caller must walk the pages. No code reads it:
`fetch_all_matching` sends its own `limit` (`PAGE_SIZE`, 200) and walks each
page to the end, whatever size the server chose. A fix changes one parenthesis
of a module doc. That change starts one more review cycle and changes no
behavior.

**The boundary.** Code that depends on the default page size of the server, or
that stops a walk because a page holds fewer items than a fixed number, is a new
occurrence. The number in the doc is settled.
