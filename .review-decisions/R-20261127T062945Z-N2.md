## `src/nle/src/commands.rs` — no test writes through a link to a file that does not exist

**Settled** 2026-11-27 (branch issue-158, finding R-20261127T062945Z#N2)

The finding is accurate. The doc of `resolve_output_path` says that a link to
a file that does not exist ends at that file, and that the write creates it.
No test writes through such a link. `save_recording_to_writes_through_a_symlink`
links to a `rec.json` that exists.
`video_export_args_gives_beta_the_target_of_a_symlink` links to a missing
`real.mp4`, but it reads only the `--output` argument, and it writes no file.

The gap is small, because each step of the write has a test or is a few lines
of plain code:

- `follow_links` ends the chain when `symlink_metadata` of the current path
  fails. Thus a missing target ends the chain. The test of
  `video_export_args` proves this step for a missing file.
- `resolve_output_path` then needs only the parent directory of the end of the
  chain. The file itself can be absent.
- `json_file::save` writes a temporary file in that directory and renames it
  over the path. A rename creates a path that does not exist, and a save to a
  new path gives the mode that `File::create` gives.
- `save_recording_to_writes_through_a_symlink` proves that the write goes to
  the end of the chain and keeps the link.

The cost of a fix: one more unix test in `src/nle/src/commands/tests.rs`. The
round that read this finding was record-only. A new test is new code that a
review must read, and it starts one more review round, which can find a new
nit in the new code.

The boundary: a report that no test writes through a link to a missing file is
this decision. These changes reopen it:

- A write through a link to a missing file fails, or it replaces the link with
  a file.
- `follow_links` or `resolve_output_path` changes how it ends a chain at a
  missing file, for example with a `canonicalize` of the whole path.
- `json_file::save` stops the rename of a temporary file over the path, for
  example with a write in place that opens the path through the link.
