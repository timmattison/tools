## `src/nle/src/editor.rs` `Edit` — the doc does not name a chapter in the list of missing targets

**Settled** 2026-11-28 (branch issue-164, finding R-20261128T051847Z#N4)

The finding is accurate. The doc of `Edit` says that an edit that names a
clip, a track, or a filter index that does not exist is refused with
`NleError::EditError`. `RemoveChapter` and `UpdateChapter` also refuse a
missing chapter id with that error, through `chapter_position` and
`missing_chapter`. The list does not name a chapter. Nothing in the doc is
false.

The fix costs more than the defect. The fix is prose. The branch is in the
record-only round of the review loop. A rewrite is new text that a fresh
review reads, and a nit in it starts one more fix round. The error message
`chapter <id> does not exist` and the code of both arms state the refusal.

The boundary: this record settles only the omission of a chapter from the
list of missing targets in the doc of `Edit`. A sentence of that doc that is
false at the head of the branch is a new finding. A chapter edit that does
not refuse a missing id is a new finding too.
