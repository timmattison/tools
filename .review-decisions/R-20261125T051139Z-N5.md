## `src/workit/tests/output.rs` — the test of the dropped members searches all of stderr for `keep`

**Settled** 2026-11-25 (branch workit, finding R-20261125T051139Z#N5)

The finding is accurate. The test asserts that stderr does not hold the text
`keep`. The `Dropping` message prints the path of the manifest, and that path
holds the temporary directory of the user and the random name of the `TempDir`
of the fixture. If either holds `keep`, a correct run fails.

It is not fixed, because the fix costs more than the defect:

- **The chance is very small.** `TempDir::new` of `tempfile` names the
  directory `.tmp` and 6 random letters and digits, from 62 characters. The
  chance that those 6 characters hold `keep` is 3 in 62⁴, about 1 in 5
  million. The temporary directory of the user does not change between runs.
  On this Mac it is below `/var/folders` and does not hold `keep`.
- **A failure is loud and easy to read.** The message of the assertion prints
  stderr, and the path that holds `keep` is in that text.
- **The cost is a new review cycle.** This round of the review loop is
  record-only. A comparison of whole lines is new code in a test file that a
  review must read, and a fresh review can find a new nit in it. Tim chose to
  settle each nit with a record (decision H-742-2 on issue #742).

**The boundary.** This decision settles this one assertion. A failure of this
test because a path holds `keep` reopens it.
