## `src/msgs/frontend/src/messages.ts` — an empty page of older messages removes the `Unknown date` separator

**Settled** 2026-11-24 (branch msgs, finding R-20261124T232234Z#N4)

The finding is accurate. When a page of older messages comes back empty,
`chronological` is empty, and `formatDateSeparator(null)` gives
`UNKNOWN_DATE_LABEL`. If the first separator on the screen is the
`Unknown date` separator of the oldest, undated messages, the code removes it
and inserts nothing. The oldest group then shows no separator.

**The fix costs more than the defect.** The defect needs two conditions at the
same time: a chat that holds an exact multiple of 50 messages, and undated
messages at the start of that chat. The result is one missing label above
messages that have no date. No message disappears. The fix is one condition
and a vitest test. But this round of the review loop is record-only, thus that
code starts one more review cycle.

**The boundary.** This record settles the empty page of older messages only. A
separator that disappears or shows two times for a page that holds messages
reopens this record.
