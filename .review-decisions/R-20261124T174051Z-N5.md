## `src/faulte/src/top.rs` tests — the doc of the delay test sits on the test of the endless list

**Settled** 2026-11-24 (branch issue-669, finding R-20261124T174051Z#N5)

The finding is accurate. Commit `0d996236` put the test
`the_stream_arguments_ask_for_endless_samples` between the doc comment of
`the_delay_is_a_bare_number_of_seconds` and that test. Thus the doc about the
delay in seconds sits on the test of the `-l 0` list, where it is false, and
the delay test at `top.rs:757` has no doc comment.

The fix moves two lines of comment in a test module. The round that found it
was record-only, and a moved comment is a change that the next review must
read. That review starts one more round, and the round costs more than the
defect. Rustdoc does not show the doc of a test function, and the name of each
of the two tests states its rule.

The boundary: this settles the position of this one doc comment in the tests
of `top.rs`. A misplaced or false doc comment at a different test is a new
occurrence, not a new argument about this one. A test whose name states a
rule that its body does not hold is a new finding.
