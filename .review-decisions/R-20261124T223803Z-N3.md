## `src/faulte/src/history.rs:1025` — the doc of `bytes_used` says that it counts each container (third report)

**Settled** 2026-11-24 (branch issue-669, finding R-20261124T223803Z#N3)

The finding is accurate. It is the same case as R-20261124T215117Z#N1 and
R-20261124T220954Z#N4, and `R-20261124T215117Z-N1.md` gives the full reason.
The doc of `bytes_used` says that it counts each container by its capacity,
but `bytes_used` does not count the field `accounts`.

The cost is the same. The map of the names holds one name for each account
of the Mac, thus some kilobytes against a budget of 64 MiB. A change of the
doc or of the count in a record-only round starts one more review round, and
that round costs more than the omission.

The boundary: the same as R-20261124T215117Z#N1. A new report of `accounts`
is the same case, not a new occurrence.
