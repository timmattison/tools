## `src/nle/src/preview/tests.rs` `the_number_of_snapshots_has_a_limit` — the bound writes `MAX_SNAPSHOTS` as the literal 256

**Settled** 2026-11-26 (branch issue-151, finding R-20261127T022554Z#N1)

The finding is accurate. The test asserts `snapshot_count() <= 2 * 256 + 1`,
and `MAX_SNAPSHOTS` in `src/nle/src/preview.rs` is 256. The test module imports
`super::*`, thus the constant is in scope.

The test holds the correct property today. An 80x24 grid reaches
`MAX_SNAPSHOTS`, and a mutant that removes the limit of the snapshots fails the
test. Only a later change of the constant makes the literal wrong. If the
constant increases, the test fails loudly. If the constant decreases, the bound
of the test is loose, but it still finds a preview with no limit.

of a test is a diff that a review must read, and that review can find a new nit
in it. Then one more fix round starts.
