`is_self = name == self_name`. Commit `af8027eb3` of this branch changed that
rule. `is_self` is now also true when `name` is another name of the tree of the
invoking user, by a compare of the canonical paths.

design record of 2026-07-22. This branch does not change the spec, and no
build, test, or user reads it. The current rule is in two places that a reader
finds first:

- the doc comment of `user_projects` in `src/crap/src/main.rs`, and
- the text of `--user` in `README.md`, which a user reads.

This round of the review loop is record-only. A change of the spec starts one
more review cycle.

**The boundary.** This record settles only the statement of the spec about the
body of the private function `user_projects`. That function is not a contract:
nothing outside `src/crap/src/main.rs` calls it. The record
`R-20261124T232234Z-N7.md` keeps a false statement about a contract open, and
this record does the same. A false statement of this spec about the behavior of
