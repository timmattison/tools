## `src/nle/src/commands.rs` — `resolve_output_path` refuses a bare relative file name with an empty path in its message

**Settled** 2026-11-25 (branch 170, finding R-20261125T021115Z#N1)

The finding is accurate. `Path::new("out.json").parent()` is `Some("")`, and
`Path::new("").exists()` is false. Thus `resolve_output_path` refuses
`out.json` with the message `Parent directory does not exist: `, which names
no path.

No user can see this message today. The frontend calls only `load_recording`.
It does not call `save_recording`, `export_video`, or `export_web`, which are
the commands that use `resolve_output_path`. The file dialog of Tauri gives an
absolute path. A relative path is also not useful in a desktop application,
because the user did not choose the current directory of the process. Thus the
refusal is correct, and only the text of the message is poor.

The cost of a fix: a red test, a green change, and one more review round, for a
message that no caller can show. The first frontend call to one of these three
commands brings `resolve_output_path` back into a review.

The boundary: a report that a bare relative name gets the empty message is this
decision. A frontend call that can send a relative path to one of the three
commands reopens it, and so does an empty message for an absolute path.
