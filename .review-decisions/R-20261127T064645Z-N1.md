## `src/nle/src/ui/tests.rs` — the name of `the_speed_panel_shows_its_fields_and_the_edited_duration` stays

**Settled** 2026-11-27 (branch issue-162, finding R-20261127T064645Z#N1)

The finding is accurate. On `main` (`baa8d7de0`), the Edited duration row was
inside `SpeedPanel`. This branch moved the row into `PropertiesPanel`, after
`SpeedPanel` and `FastForwardPanel`. The name of the test still says that the
speed panel shows the duration, and that statement is now false.

No assertion is wrong. The body asserts that the page holds the row one time,
with the value `1m 5.3s`. That assertion is true in the new layout.
`the_edited_duration_follows_both_panels` holds the new position of the row, so
the suite states the layout correctly in one place.

The fix is a rename of one test. The cost is one more review cycle of the
review loop, because the rename is new code that a review must read. The defect
is a name that misleads a reader, and it changes no result of the suite. Thus
the cost is more than the defect.

The boundary: this decision settles the name of this one test on branch
issue-162. An assertion of a test that is false in the new layout is a new
finding. A different test whose name states the old layout is a new occurrence,
not a new argument about this one.
