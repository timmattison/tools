The finding is accurate. The fix round `b039633f` added the sentence about the

The cost of the defect is small. `rustfmt.toml` sets no comment width, so no
gate reads the width. Rustdoc joins the lines of a paragraph, so the rendered
documentation is the same with and without a wrap. Only a person who reads the
source sees one long line.

**The fix costs more than the defect in this round.** A wrap changes 2 or 3
lines of a Rust source file. That change is new code that a review must read,
and that review can find a new nit in it. Then one more fix round starts. This
round of the review loop is record-only.

**The boundary.** This record settles only the width of line 8 of the module
doc of `idle_compression.rs`. These occurrences reopen it:
