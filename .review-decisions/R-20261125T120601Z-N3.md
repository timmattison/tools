## `src/nle/frontend/src/App.css` — a long `.metadata-value` cannot shrink or wrap

**Settled** 2026-11-25 (branch 170, finding R-20261125T120601Z#N3)

The finding is accurate. `.metadata-value` is a flex item of `.metadata-item`,
which has `display: flex`. Its `min-width` is the default `auto`. Thus a long
token with no space, for example a path argument in the command or a long title,
cannot shrink or wrap, and it pushes the row past the right edge of the
properties panel.

The defect is a layout defect only. The panel shows the full value, and no data
changes. The file row of the panel shows only the last part of the path, and
its `title` attribute holds the full path.

The cost of a fix: a change to `App.css`, and one more review round, for a
layout defect that only a long token with no space causes. No test of this
repository renders CSS, thus a fix has no test that can fail.

The boundary: a report that a long token overflows the properties panel is this
decision. An overflow that hides a control of the panel, or a value that a user
cannot read in any form, reopens it.
