## `src/termstate` — IL and DL ignore the scrolling region

**Settled** 2026-11-27 (branch issue-165, finding R-20261127T201651Z#N3)

The finding is accurate. IL (`CSI L`) and DL (`CSI M`) in
`src/termstate/src/lib.rs:1855-1884` move the rows down to, or up from, the
last row of the screen, and they ignore `scroll_bottom`. xterm limits IL and DL
to the region, and ignores them when the cursor is outside the region. The IL
and DL arms of `bf33efbb`, the merge base of this branch, have the same loops
(line 1392 of that commit). This branch changed only the count and the marks
of the rows in those arms.

The defect is a margin defect older than this branch, as
`.review-decisions/2026-11-27-issue-165-termstate-scrolling-region-follow-up.md`
defines it. Tim decided that such a defect is not fixed on this branch. Thus
this commit adds the defect to the list of that record, as entry 2, with its
reproduction.

**The fix costs more than the defect on this branch.** The fix is a red test
and a green commit in `termstate`, and it changes the rows that IL and DL mark
in `each_change_of_a_cell_marks_its_row`. Tim's decision puts that work into
the follow-up issue. Also, this round of the review loop is record-only. A
change is a diff that a review must read, and that review can start one more
fix round.

**The boundary.** This record settles only the rows that IL and DL move. A
change of this branch to IL or DL that changes which rows move is not older
than the branch, and the follow-up record does not cover it.
