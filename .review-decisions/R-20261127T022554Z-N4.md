## `README.md` `nle` Preview — "about one for each second" states the shortest interval of the snapshots as the usual one

**Settled** 2026-11-26 (branch issue-151, finding R-20261127T022554Z#N4)

The finding is accurate. `Preview::new` in `src/nle/src/preview.rs` sets the
interval to `max(duration / budget, MIN_SNAPSHOT_INTERVAL)`, and `budget` is 1
to `MAX_SNAPSHOTS` from the size of the grid. Thus an 80x24 recording longer
than 256 s, or a 500x500 recording longer than about 15 s, gets fewer than one
snapshot for each second. The README says "about one for each second of the
recording". One second is the shortest interval, not the usual one.

The next sentence of the README states that the number of snapshots has a limit
that depends on the size of the grid. Thus the text does not hide the limit. It
only puts the wrong weight on the shortest interval.

one more fix round starts.
