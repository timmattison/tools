## `src/ha/src/board.rs` — the doc of the test helper `run_job_sum` says "shows" for the job sum that the row carries

**Settled** 2026-11-27 (branch issue-749, finding R-20261127T145147Z#N2)

The review found that the doc of the test helper `run_job_sum` says that the row
shows the job sum. On this branch, the row of an active run with an estimate
shows the estimate in place of its job sum (`run_line` in `render.rs`). The
helper reads the `job_sum` field, not the shown cell. The finding is accurate.
The helper `run_remaining_of` above it says "carries", which is the correct
word.

The fix is one word in the doc of a test helper. It changes no test and no
behavior, and it starts one more review cycle of the review loop. That cycle
costs more than the wrong word.

**The boundary.** This decision covers only the word in the doc of
`run_job_sum`. A test that reads the `job_sum` field to prove what the row
shows is a new finding.
