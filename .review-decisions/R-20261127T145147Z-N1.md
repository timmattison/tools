## `src/ha/src/estimate.rs` — the doc of `Remaining::Left` and of `run_remaining` does not name `AtLeast(0)` for a run at its estimate

**Settled** 2026-11-27 (branch issue-749, finding R-20261127T145147Z#N1)

The review found that the doc of `Remaining::Left` and the doc of
`run_remaining` say that a run exactly at its estimate gives `Left(0)`. When a
job that waits gives the latest term, `wrap(0)` returns `AtLeast(0)`, which
renders as `>0s`. The finding is accurate, and the code is correct: `AtLeast(0)`
is the better value for that case.

The case needs an any-runner mean of 0 s and a tail of 0 s, thus it is rare.
The fix is a change of prose only. It changes no behavior, and it starts one
more review cycle of the review loop. That cycle costs more than the imprecise
sentence.

**The boundary.** This decision covers only the words of the two docs about a
run at exactly zero. A wrong value from `run_remaining`, or a doc that names a
wrong variant for a case that is not at zero, is a new finding.
