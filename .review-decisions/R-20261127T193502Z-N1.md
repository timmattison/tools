## `src/nle/src/ui/tests.rs` `Specificity::of` and `style_selectors` — the helpers read only the forms that `main.css` holds now

**Settled** 2026-11-27 (branch issue-824, finding R-20261127T193502Z#N1)

The finding is accurate. It repeats R-20261127T193101Z#N1 (see
`R-20261127T193101Z-N1.md`) and adds one more gap. `style_selectors` splits the
style sheet at each `}` and takes the text before the next `{`. A comment
before a selector stays in that text, and a rule inside `@media` gives the
prelude of the at-rule. In both cases `starts_with("button:hover")` is false,
and the test `the_dismiss_button_keeps_its_own_hover_color` skips the rule in
silence.

The test is correct now. `src/nle/assets/main.css` (256 lines) holds no
pseudo-element, no at-rule, and no comment before a selector. Its one comment
is inside the `.terminal` rule. The test also fails loudly in two of the cases.
If the test skips each `button:hover` rule, `every_button` is empty and the
test fails. If a comment comes before `.error-dismiss:hover`, `rank` finds no
rule and the test fails.

**The fix costs more than the defect.** The fix of the finding is to remove a
sentence of doc prose and to state the limit of the helpers. That fix changes
no behavior. It is new text that a review must read, and a new fix round then
starts. A parser that reads comments and at-rules is the opposite fix. It makes
test helpers of about 130 lines larger for one CSS rule of 3 lines.

**The boundary.** This record settles only the forms that the helpers do not
read: a pseudo-element, a comment before a selector, and a rule inside an
at-rule. These occurrences reopen it:

- one of those forms in `main.css` on a rule that starts with `button:hover`,
  or on the `.error-dismiss:hover` rule
- a new caller of `style_selectors` or of `Specificity::of`
