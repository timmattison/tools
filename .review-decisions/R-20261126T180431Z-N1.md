## `src/httpfile/src/pool.rs` — the sentence "Only an unexplained `recv()` error ends the pool" stays

**Settled** 2026-11-26 (branch issue-441, finding R-20261126T180431Z#N1)

The finding is accurate. The doc of `Pool::spawn` says that only an
unexplained `recv()` error ends the pool. When each worker panics, the pool
ends too, and `Pool::join` reports it. Read alone, the sentence with "Only"
is false in that case.

The code is correct. The sentence is in the paragraph about an `Err` from
`handler`, and the next paragraph says that a panic ends its worker and that
`Pool::join` reports it. The tests of `src/httpfile` and `src/sirn/tests/pool.rs`
hold the behavior of a pool whose workers all panicked.

The cost of a fix: the fix is prose in a doc comment. It fixes no behavior,
and it is new text that the next review reads. Thus it starts one more review
round, which can find a new nit in the new words.

The boundary: a report about the words of this doc comment is this decision.
This change reopens it:

- The behavior changes, so that a pool whose workers all panicked does not
  end, or `Pool::join` does not report it.
