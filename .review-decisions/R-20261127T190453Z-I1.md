## merge `a9010de4` — no red commit came before the two behaviors that the merge added, and the merge stays

**Settled** 2026-11-27 (branch issue-165, finding R-20261127T190453Z#I1)

The finding is correct. The merge `a9010de4` of `origin/main` into this branch
added two behaviors that neither parent had, and their tests, in one commit:

1. A span filter after a screen filter gets the size that the screen filter
   gave. The code is the `Registered::Span` arm of the render in
   `src/nle/src/pipeline.rs`. The test is
   `a_span_filter_after_a_screen_filter_gets_the_size_that_the_screen_filter_gave`.
2. `TerminalState::eq` compares nine more fields: `current_fg_source`,
   `current_bg_source`, `dim`, `blink`, `reverse`, `hidden`, `strikethrough`,
   `autowrap`, and `wrap_pending`.

Each behavior resolves a conflict. `main` added `SpanContext::size` and
`PartialEq for TerminalState`. This branch added the screen form and the nine
fields. A merge that keeps both sides must give a size to a span filter after a
screen filter, and it must compare or skip each new field.

The fix is a new merge with no new behavior, then a red commit and a green
commit for each behavior. It has these costs:

- The branch must move back to `a37ee756`. The git guardrail refuses a hard
  reset, and it has no override. Only Tim can run it, and the review loop runs
  with no person.
- The review R-20261127T190453Z read `a9010de4`. A new merge, red, and green
  get new SHAs, thus a new review must run.
- The rewrite changes no behavior. The squash merge gives `main` one commit,
  thus the order of the commits of the branch does not go into the history of
  `main`.

The cost of the fix is thus more than the cost of the defect.

In place of the red commits, a mutant of each behavior shows that a test fails
without it. Each mutant stayed out of the repository. The mutant of the size
changes `size: size.unwrap_or(TerminalSize::VT100)` to
`size: TerminalSize::VT100`. The mutant of a field changes `*f == other.f` to
`*f == *f`, one field at a time.
