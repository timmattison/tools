## `README.md` (nle) — the README gives the install before the port

**Settled** 2026-11-25 (branch 170, finding R-20261124T235134Z#N1)

The finding is accurate. Lines 3375-3376 of `README.md` say that
`src/nle/scripts/dev.ts` installs the frontend dependencies and then asks
`portplz` for a port. The script does the checks of the tools, asks `portplz`,
and does a check of write access before `pnpm install`. The header of `dev.ts`
(lines 8-12) gives the correct order and the reason for it.

It is not fixed, because:

- **The order does not change what a reader does.** The README tells the
  reader to run one command. The reader sees each step and each failure in the
  output of that command. Only a missing tool makes the order visible, and then
  the script stops with a message that names the tool and its repair.
- **The round is record-only.** A change to the README is new text that a
  review must read, and it starts a new review cycle.

The boundary: a README text that tells the reader to do a step by hand in the
wrong order, or a change to the order of the steps in `dev.ts`, reopens this
decision.
