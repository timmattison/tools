## `specs/2026-11-26-nle-plugin-architecture-design.md` step 5 of the install — a crash between the two renames of an update leaves no loaded copy

**Settled** 2026-11-26 (branch issue-169, finding R-20261126T223433Z#N2)

The finding is accurate. Step 5 of "Load from a URL" updates a plugin with two
renames. The first rename moves the old folder to a name that starts with `.`.
The second rename moves the new folder into place. If the editor stops between
the two renames, no folder of that plugin loads at the next start. Each project
that names the plugin then fails to render until the user installs the plugin
again.

The defect needs a crash in the short time between two renames of one
directory. Nothing is lost. The old copy and the new copy both stay on the
disk, and a new install from the same URL repairs the state. Nothing in the
spec removes the old copy, thus it keeps its disk space.

**The fix costs more than the defect in this round.** The swap that the
finding gives is not in `std`. It is `renameat2` with `RENAME_EXCHANGE` on
Linux, and `renamex_np` with `RENAME_SWAP` on macOS. Thus the editor needs
`unsafe` code or a new dependency, and a test on each platform. A recovery at
start is a different fix, and it is a new rule of the load with its own test.

This round of the review loop is record-only. A change of the spec starts one
more review cycle, and that review can find a new nit in the new text. Slice 7
writes the install code, and a review of slice 7 reads the real renames.

**The boundary.** This record settles only the window between the two renames
of an update, and the old copy that a crash in that window leaves. The records
of R-20261127T030328Z#N1 and R-20261127T032320Z#N4 settle the same subject
from other findings. Each of these occurrences reopens this record:

- the install code of slice 7 has the same window between two renames, with
  no recovery and no test of a crash in the window
- an update deletes the old copy before the new copy is in place
- the spec says that an update is safe from a crash
