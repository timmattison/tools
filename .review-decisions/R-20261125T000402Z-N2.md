## `README.md` (nle) and the body of PR #172 — both give the install before the port

**Settled** 2026-11-25 (branch 170, finding R-20261125T000402Z#N2)

The finding is accurate. Lines 3375-3376 of `README.md` and the Dev script
section of the body of PR #172 (issue #170, branch 170) give `pnpm install`
before `portplz`. `src/nle/scripts/dev.ts` asks `portplz` (line 81) and does a
check of write access (line 104) before `pnpm install` (line 114). Its header
(lines 11-12) says that this order is on purpose.

R-20261124T235134Z#N1 reported the README half of this finding.
`R-20261124T235134Z-N1.md` in this directory settles that half.

It is not fixed, because:

- **The order does not change what a reader does.** The reader runs one
  command and sees each step and each failure in its output. Only a missing
  tool makes the order visible, and then the script stops with a message that
  names the tool and its repair.
- **The PR body is not a file of the branch.** No code, no test, and no guard
  reads it.
- **The round is record-only.** A change to the README or to the PR body is new
  text that a review must read, and it starts a new review cycle.

The boundary: a text that tells the reader to do a step by hand in the wrong
order, or a change to the order of the steps in `dev.ts`, reopens this
decision.
