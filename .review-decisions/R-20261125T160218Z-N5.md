## `src/ufa/src/test_server.rs` — the doc of `TestServer` names one canned response

**Settled** 2026-11-25 (branch ufa, finding R-20261125T160218Z#N5)

The finding is accurate. The doc of `TestServer` says that the server writes
back the one canned response that it was built with. `TestServer::routing`
picks an answer by the request line, `TestServer::silent` writes nothing, and
`TestServer::hanging_up` closes the connection with no answer.

**The cost is a new review cycle.** The fix is prose in a test helper. This
round of the review loop is record-only, and a fresh review reads the changed
doc and can find a new nit in it. Then a new fix round starts, and the loop
does not end clean. No user reads this doc. Each constructor has its own doc,
and that doc states what the server answers: `routing` names its routes and
its fallback, `silent` keeps the connection open with no answer, and
`hanging_up` closes it with no status. A test author reads the doc of the
constructor that the test calls.

**The boundary.** This decision settles only the doc of the struct
`TestServer`. A constructor whose own doc states a wrong answer is a new
finding.
