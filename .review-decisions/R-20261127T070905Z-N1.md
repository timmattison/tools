## `README.md` — the Summarize bullet names its fields by the start of each label

**Settled** 2026-11-27 (branch issue-162, finding R-20261127T070905Z#N1)

The finding is accurate. The Summarize bullet of the fast-forward panel writes
**First lines** and **Last lines**. The labels are `FIRST_LINES_LABEL`
("First lines (Summarize)") and `LAST_LINES_LABEL` ("Last lines (Summarize)")
in `src/nle/src/ui.rs`. The Accelerate bullet writes the full label
**Speed (Accelerate)**, thus the two bullets do not agree.

A reader finds each field, because the bold text is the start of its label,
and the bullet itself names Summarize. No statement of the bullet is false.

The fix is a change of two words in one line of the README. The cost is one
more review cycle of the review loop, because the change is new text that a
review must read. The defect is a difference of style between two bullets, and
it sends no reader to a wrong field. Thus the cost is more than the defect.

The boundary: this decision settles the names of the two Summarize fields in
this bullet on branch issue-162. A README name that matches no label, or the
start of a different label, is a new finding. A different bullet that names a
field by part of its label is a new occurrence, not a new argument about this
one.
