get the form reports clean for that form.

the coverage of a state that does not exist today. Each copy agrees with the
others now, and each test passes for each form that the scanner has. The gap
can hide no defect of the code that this branch ships.

The fix is a change of test code: one constant for the six forms, and a slice
of it in the stop test. This round of the review loop is record-only. A change
of test code starts one more review cycle, and that review can find a new nit
in the new constant.

**The boundary.** This record settles only the three copies of today, which
agree. Each of these occurrences reopens it:
