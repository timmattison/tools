## `src/ufa/src/http.rs` — the module doc names one difference between the two APIs, and there are two

**Settled** 2026-11-25 (branch ufa, finding R-20261125T182148Z#N3)

The finding is accurate. The module doc says that the name of the API is the
only thing that differs between the two APIs. The `Api` enum also picks the
advice about the key after a 401 or a 403 (`authentication_failure` and
`key_refusal`). The doc of `Api` states both differences.

**The cost is a new review cycle.** The fix is prose in a module doc. This
round of the review loop is record-only, and a fresh review reads the changed
doc and can find a new nit in it. Then a new fix round starts, and the loop
does not end clean. A caller picks an `Api` value, and the doc of `Api` gives
the two differences at that point. The module doc omits one difference, but it
states nothing that a caller can act on wrongly.

**The boundary.** This decision settles only the list of differences in the
module doc of `http.rs`. A third difference that no doc names, or a doc of
`Api` that is wrong, is a new finding.
