## `src/ufa/src/prompt.rs` module doc — "every question and every note goes to standard error" is wider than the setup wizard

**Settled** 2026-11-27 (branch ufa, finding R-20261127T145031Z#N3)

The finding is accurate. The module doc of `prompt.rs` (since `0258e420`)
says: "Every question and every note goes to standard error." The `Stdio`
console of that module writes its questions to standard error. But the setup
wizard in `src/ufa/src/config.rs` prints its menus and its notes to standard
output with `println!`, under `#[expect(clippy::print_stdout)]`. The reason
of that expectation is that the wizard has no `--output` format.

**The fix is prose.** The defect is the text of a doc comment, not a behavior.
The rule of the doc protects the commands that have `--output json`. The
wizard states its exception at each site, in the reason of its `expect`
attribute. A change of the doc comment changes no
behavior, and it starts one more review cycle. This round of the review loop
is record-only.

**The boundary.** This record settles only the width of that sentence in the
module doc. Each of these occurrences reopens it:

- a command with an `--output` format that prints a question or a note to
  standard output
- a print to standard output in the wizard with no `expect` attribute that
  gives its reason
