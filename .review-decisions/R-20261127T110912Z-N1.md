## `src/wdid/src/command_words.rs` `Argument::text` — a public method that nothing calls

**Settled** 2026-11-27 (branch issue-729, finding R-20261127T110912Z#N1)

The finding is accurate. Commit 7efbd08bd added the public method
`Argument::text`, and no code in `src/wdid` calls it. The callers use
`shell_text`, `is_all_arguments`, and a comparison of the whole `Argument`.
No other crate of the workspace depends on `wdid`, thus no caller exists
outside the crate. The method is `pub` in a library crate, thus the
`dead_code` lint does not find it.

The defect is small. The method has 6 lines, it reads one field, and it
changes no behavior. Its only cost is one line in the public interface of the
crate that nothing uses.

The fix costs more than the defect. The branch is in a record-only round of
its review loop. A removal is a change of code that a fresh review reads, and
that review can find a new nit in it. That starts a new fix round for an
unused accessor.

The boundary: this decision settles `Argument::text` only. If a later change
adds a caller, the method is no longer dead and this decision closes. If a
later change adds a different public method that nothing calls, that method
is a new occurrence, and this decision does not cover it.
