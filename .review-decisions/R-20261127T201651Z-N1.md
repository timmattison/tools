## `termstate::ColorSource::Default` — the doc does not name SGR 39 and SGR 49

**Settled** 2026-11-27 (branch issue-165, finding R-20261127T201651Z#N1)

The finding is accurate. The doc of `ColorSource::Default`
(`src/termstate/src/lib.rs:355`) names SGR 0, RIS, and a cleared cell. Commit
`da72feb6` made SGR 39 and SGR 49 give `Default` too (lines 1324-1333). Those
two codes change only the source, and the pen keeps the RGB value of the color
before them (decision H-165-2). The doc does not say that `Default` can be
next to an RGB value that is not the color of the theme.

The defect is in prose only. The code is correct. The test
`a_cell_after_sgr_39_and_49_has_the_default_source_and_the_old_rgb_value`
holds the behavior, and the comments in the arms of SGR 39 and SGR 49 name
decision H-165-2. Record `R-20261127T074810Z-N3.md` settles the docs of
`Indexed` and `Rgb`. This record settles the doc of `Default`.

**The fix costs more than the defect in this round.** The fix is prose: one
line of a doc comment. This round of the review loop is record-only. A change
is a diff that a review must read, and that review can find a new nit in it.
Then one more fix round starts.

**The boundary.** This record settles only the list of causes in the doc of
