## `src/nle/run-nle.sh` — the script reads no -h/--help

**Settled** 2026-11-24 (branch 170, finding R-20261124T193420Z#N1)

`run-nle.sh` reads no argument. Thus `run-nle.sh --help` starts
`cargo tauri dev`, and it does not print the usage comment of lines 2-5. Item 6
of the shell script style guidelines in `CLAUDE.md` asks for `-h`/`--help`, and
most shell scripts of this repository have it.

The finding is accurate. It is not fixed, because:

- **The script has no option to tell.** Its full use is
  `./src/nle/run-nle.sh`, and the usage comment at the top of the file gives
  that line.
- **A `--help` causes no damage.** It does the same thing as a run with no
  argument: it starts the dev server, and Ctrl-C stops it.
- **The fix is new shell code and a new test, in a record-only round.** The
  test goes in `src/nle/tests/run-nle-script.rs`. Both start a new review
  cycle.

The boundary: the first option that the script reads reopens this decision,
because a script with options must tell them. A decision by Tim to apply item 6
to each script also reopens it.
