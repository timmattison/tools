**Settled** 2026-11-25 (branch ufa, finding R-20261125T182148Z#N1)

The finding is accurate. The row for no flag says "Anything but `y` aborts."
`answered_yes` in `src/ufa/src/prompt.rs` trims the answer and takes `y` or
`yes` in any letter case. Thus `yes` and `Y` also delete.

**The cost is a new review cycle.** The fix is prose in the README. This round
of the review loop is record-only, and a fresh review reads the changed row
and can find a new nit in it. Then a new fix round starts, and the loop does
not end clean. The harm is none in practice. Each answer that the row omits,
`Y`, `yes`, and `YES`, is a yes, and a person who types one of them to a
question about a deletion wants the deletion. The row is correct about each
answer that aborts.

**The boundary.** This decision settles only the list of answers that delete,
in that row. A prompt that deletes on an answer that a person types to mean
no, or a doc that says that such an answer deletes, is a new finding.
