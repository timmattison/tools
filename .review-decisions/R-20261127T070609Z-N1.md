## `src/nle/src/ui/chapters.rs` chapter panel — the empty-list text beside the keyed rows

**Settled** 2026-11-27 (branch issue-164, finding R-20261127T070609Z#N1)

The finding is accurate about the shape. In `div.chapters-panel`, the
`if total == 0 … else if rows.is_empty()` text is a conditional element
beside the keyed `for row in rows` loop. The rule "one section of a list
takes its items from one source" in `~/.claude/CLAUDE.md` names that shape.

The failure that the rule prevents does not occur here. UIKit counts the
rows of one section and fails on a delete with no matching insert. Dioxus
gives the `if` and the `for` of an `rsx!` block different dynamic slots, and
it diffs the keyed rows of the `for` slot alone. The empty text and the rows
also never show at the same time: the text shows only when `rows` is empty.

The fix costs more than the defect. A wrapper `div` changes the markup of the
panel. A fresh review reads that change, and the loop then starts one more fix round for a shape that has no
failure in this framework.

The boundary: this settles the empty-list text of the chapter panel at
`78bd494f8`, under Dioxus. A conditional row that can show together with the
keyed rows, a move of this panel to a framework that diffs one list per
parent, or a failure that a person sees in this panel, is a new finding.
