## `src/faulte/src/machine.rs:460` — the doc of `sample_window` describes only the one-shot caller

**Settled** 2026-11-24 (branch issue-669, finding R-20261124T223803Z#N1)

The finding is accurate. The doc of `sample_window` says that `top` prints
the local time of each of its two samples, and that `wall` is the time that
the whole run of `top` took. That text describes `observe`, which runs
`top -l 2`. This branch added a second caller, `Run::send_sample`
(`sampler.rs:296`). It passes `sample.wall`, which is the monotonic time
between the arrivals of the two headers that bound the sample
(`HeaderStamps::header`, `stream.rs:532-542`). Its `elapsed` is the difference
of two adjacent clock lines of an endless `top`.

The clamp is correct for both callers. The window is never shorter than the
interval, and never longer than the monotonic time that the caller measured.
Only the names in the doc describe the one-shot caller alone.

The fix is prose in a doc comment. The round that found it was record-only,
and a changed comment is new text that the next review must read. That
review starts one more round, and the round costs more than a doc whose rule
is correct for both callers.

The boundary: this settles the wording of the doc of `sample_window`. A
caller for which the clamp itself gives a wrong window is a new finding.
