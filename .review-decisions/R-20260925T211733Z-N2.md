## Commit order on a pushed branch — the remote lookup of `-b` landed with more than its red test asked for

**Settled** 2026-09-25 (branch issue-528, finding R-20260925T211733Z#N2)

The review found that the commit that added the remote lookup of `nwt -b <name>`
(`d8f8bee0` when the review ran, `f7a48533` after the branch was rebased onto `main`)
does more than its red test (`802c3b81`, now `67f54c4a`) asks for. It also brings the
sparse check of the tracked ref, the removal of a tracked branch after a failed step,
and the error for a failed listing, and it commits four unit tests in the same commit
as the code. The TDD rule in `CLAUDE.md` asks for a red commit for each behavior. The
finding is accurate.

It is not fixed, because the defect is the order and the grouping of commits, and
nothing else.

**The coverage is real, and it was shown to fail.** The sparse behavior and the
cleanup behavior got guard tests in later commits (`557bc2e3` and `c4a8635c` after the
rebase). The body of each guard commit records a mutation check, so each test was seen
to fail for the behavioral reason. The review states the same thing and asks for no
change to this branch.

**The one fix is a history rewrite, and it buys nothing that lasts.** The branch is
published as PR #532. To split the commit, a rebase must rewrite history that is
already pushed, and the next push must be a force push, which the git guardrail of
this machine refuses. This repository squash-merges every pull request with an
explicit `--subject` and `--body`, so no commit of this branch reaches `main`. The
merge discards the grouping in any case.

**The boundary.** This decision settles the grouping of commits that are already
pushed on a branch that is squash-merged, where each behavior has a test that was shown
to fail by the time of the review. It does not settle a missing test, or a test that
nobody showed can fail. It does not settle the order of commits on a branch that is not
pushed, where a rebase costs nothing. It follows the same reasoning as
`R-20260820T153740Z-N2.md`, and it does not make "implementation first" acceptable as
a habit.
