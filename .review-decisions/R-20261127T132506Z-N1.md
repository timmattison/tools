**Settled** 2026-11-27 (branch issue-161, finding R-20261127T132506Z#N1)

The finding is correct. Round 1 (2b1f8583) added the entries of
`src/termstate/src/tests.rs` and `src/nle/src/filters/keystroke_hud/tests.rs`
to `EXEMPTIONS`, and the array became `[Exemption; 5]`. The doc comment of the
array still names only the two entries of `altscreen` and the one of `krt`.

The fix is prose in one doc comment. This round of the review loop is
record-only. A change to the doc is new text that a review must read, and that
review can start a new fix round. The type `[Exemption; 5]` gives the count,
the `reason` of each entry gives its cause, and CLAUDE.md lists all five
entries. Thus a reader gets the correct list one line below the comment.

Boundary: this decision covers the words of the doc comment only. An entry
that the guard applies but CLAUDE.md does not list reopens it.
