## `src/ufa/USAGE-EXAMPLES.md` — the firmware recipe does not print the words of the Firmware column

**Settled** 2026-11-27 (branch ufa, finding R-20261127T130724Z#N1)

The finding is correct. The sentence says that
`jq '.[].reportedState | .firmwareVersion // .firmware_version // .version'`
reads the same value as the column. `HostRow::from`
(`src/ufa/src/site_manager/commands.rs`) prints `Unknown` when a host has no
`reportedState`, or sets none of the three keys. The recipe prints `null` in
that case. Without `-r`, it also prints each version in quotes.

The recipe reads the correct keys in the correct order, thus it gives the same
version as the column for each host that reports one. Only the empty case and
the quotes differ, and `null` is a clear answer for a program. A fix changes
one sentence of prose, and it starts one more review cycle.

**The boundary.** A recipe that reads a wrong key, reads the keys in a
different order than `ReportedState::firmware`, or gives a version that the
column does not show, is a new occurrence. The missing `Unknown` fallback and
the missing `-r` of this one sentence are settled.
