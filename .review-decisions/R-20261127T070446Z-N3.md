## `README.md` — the list of limits of the HUD omits the theme colors and `MAX_CELLS`

**Settled** 2026-11-27 (branch issue-161, finding R-20261127T070446Z#N3)

The finding is correct. The module doc of `keystroke_hud.rs` says that a
cell color of exactly one of the 18 colors of the private replay theme comes
back as its theme color. `draw` refuses a terminal of more than `MAX_CELLS`
(1,000,000) cells. The README list of limits names neither.

The fix is prose. This round of the review loop is record-only. A change to
the README is new text that a review must read, and that review can start a
new fix round. The refusal gives a message that names the size of the
terminal and the limit, and the pipeline puts that message into its render
error. Thus a user who gets the refusal learns the cause from the message.
The theme limit applies only when a cell has exactly one of those 18 colors.

Boundary: this decision covers the README text only. A render that fails with
a message that does not name its cause reopens it.
