# chf — plan for issue #674

The PRD is GitHub issue #674 (branch `issue-674`). This plan records the
decisions that the issue leaves open, and the contract between the slices. Each
slice is one TDD red/green run.

## Crates

### `src/claude-transcript` (new library crate, package `claude-transcript`)

The one definition of the transcript facts that `crap` and `chf` share. Its
dependencies are `serde` and `serde_json` (feature `raw_value`). Add
`claude-transcript = { path = "src/claude-transcript" }` to the internal crates
of `[workspace.dependencies]`.

```rust
/// The rule for a session id: a canonical UUID, 8-4-4-4-12 hex digits, either case.
pub fn is_valid_session_id(id: &str) -> bool;

/// A session id that obeys the rule. The field is private.
#[derive(Debug, Clone, PartialEq, Eq, Hash, PartialOrd, Ord, Serialize, Deserialize)]
#[serde(try_from = "String", into = "String")]
pub struct SessionId(String);
impl SessionId {
    pub fn parse(id: &str) -> Option<Self>;
    /// `<uuid>.jsonl` gives the id. Each other name gives `None`.
    pub fn from_file_name(name: &std::ffi::OsStr) -> Option<Self>;
    pub fn as_str(&self) -> &str;
}

/// `<home>/.claude/projects`. The one store location of crap and chf.
pub fn projects_dir(home: &Path) -> PathBuf;

/// One line of a transcript that parses as a JSON object. The pairs keep file order.
pub struct Record<'a> { /* Vec<(String, &'a RawValue)> */ }
impl<'a> Record<'a> {
    /// Parse one line. A trailing `\n` or `\r\n` is removed first.
    /// A line that is not UTF-8 or not a JSON object gives `None`.
    pub fn parse(line: &'a [u8]) -> Option<Self>;
    pub fn pairs(&self) -> &[(String, &'a RawValue)];
    pub fn raw(&self, key: &str) -> Option<&'a RawValue>;
    pub fn get<T: DeserializeOwned>(&self, key: &str) -> Option<T>;
    pub fn has_key(&self, key: &str) -> bool;
    /// `subtype` is the string `compact_boundary`.
    pub fn is_compact_boundary(&self) -> bool;
    /// `isCompactSummary` is `true`.
    pub fn is_compact_summary(&self) -> bool;
    /// `compactMetadata.preTokens`, when it is a u64.
    pub fn pre_tokens(&self) -> Option<u64>;
    /// A non-empty string `cwd`. The rule of crap: the first such value of a transcript wins.
    pub fn cwd(&self) -> Option<String>;
}

/// What a transcript says about its compactions.
#[derive(Debug, Clone, Copy, Default, PartialEq, Eq, Serialize, Deserialize)]
pub struct CompactionFacts {
    /// At least one compact boundary or one compact summary.
    pub compacted: bool,
    /// The count of distinct uuids of the compact boundaries.
    pub compactions: usize,
    /// `preTokens` of the LAST boundary line in file order. `None` when that line has none.
    pub last_pre_tokens: Option<u64>,
}

/// Collects the facts one record at a time, for a caller that reads each line for its own reason.
#[derive(Debug, Default)]
pub struct CompactionTally { /* ... */ }
impl CompactionTally {
    pub fn observe(&mut self, record: &Record<'_>);
    pub fn facts(&self) -> CompactionFacts;
}

/// The facts of a whole transcript. Lines that do not parse are skipped.
pub fn compaction_facts(transcript: &[u8]) -> CompactionFacts;
```

`crap` then uses the crate: `expand.rs` takes `Record` for its line predicates
and `CompactionTally` for `Expansion::compactions` and
`Expansion::last_pre_tokens`. `main.rs` takes `is_valid_session_id`,
`projects_dir`, and `Record::cwd`. Each existing `crap` test stays unchanged
and passes.

### `src/chf` (new package `chf`: a library and a binary)

`src/lib.rs` declares the modules. `src/main.rs` is the binary. Each target
root carries `#![deny(unsafe_code)]` and `#![warn(clippy::pedantic)]`, as `ha`
does (`repo_guards::target_lints` holds every root to that).

Dependencies: `blake3`, `buildinfo`, `chrono`, `claude-transcript`, `clap`,
`crossterm`, `dirs`, `ratatui`, `rayon`, `regex`, `serde`, `serde_json`,
`shellquote`, `textfit`, `unicode-width`. Dev-dependencies: `portable-pty`,
`tempfile`, `uuid`. Add a dependency only in the slice that uses it, because
`cargo machete` refuses an unused one.

## Modules of `chf`

### `session` — the data of one indexed session

```rust
pub enum Role { User, Assistant }                       // serde
pub struct MessageSpan { pub role: Role, pub start: usize, pub end: usize } // byte range in Session::text
pub struct CompactionPoint { pub before_message: usize, pub pre_tokens: Option<u64> }
pub struct Session {
    pub id: SessionId,
    pub path: PathBuf,
    pub cwd: Option<String>,             // first non-empty cwd (Record::cwd)
    pub git_branch: Option<String>,      // last non-empty `gitBranch`
    pub ai_title: Option<String>,        // last `ai-title` record, key `aiTitle`
    pub last_activity: DateTime<Utc>,    // last `timestamp` of a user or assistant record, else the mtime
    pub compaction: CompactionFacts,
    pub text: String,                    // the text of each message, joined with '\0'
    pub messages: Vec<MessageSpan>,
    pub compaction_points: Vec<CompactionPoint>, // one for each boundary line, in file order
}
impl Session {
    pub fn message_text(&self, index: usize) -> &str;
    /// `ai_title`, else the first non-empty line of the first user message, else None.
    pub fn title(&self) -> Option<&str>;
    /// `before_message` of the last compaction point.
    pub fn last_compaction_before(&self) -> Option<usize>;
}
```

All of these derive `Serialize` and `Deserialize`, because the cache stores them.

A search reads one string for each session. A query word holds no whitespace,
and `'\0'` divides two messages, thus a match never crosses two messages.

### `extract` — one transcript into one `Session`

`pub fn extract(id: SessionId, path: PathBuf, bytes: &[u8], mtime: SystemTime) -> Session`.
No file access. Rules:

- A message is a record with `type` `user` or `assistant`, without
  `isSidechain: true`, without `isMeta: true`, without `isCompactSummary: true`.
- Its text: a string `message.content`, or the `text` of each block of type
  `text` in an array `message.content`, joined with `\n`. Tool calls, tool
  results, and thinking blocks give no text. A message whose text is empty
  after a trim is not kept.
- Deserialize `message` into typed structs that skip unknown fields, not into
  `serde_json::Value`, because a tool result line can hold megabytes.
- Each compact boundary line adds a `CompactionPoint` whose `before_message`
  is the count of messages kept before it.
- The record format is internal to Claude Code. Unknown records and lines that
  do not parse are skipped. A torn last line is such a line.

### `index` — the store and the cache

```rust
pub enum IndexEvent {
    /// The count of session files found. Sent once, before the first Session.
    Total(usize),
    Session(Box<Session>),
    /// A transcript that chf cannot open or read.
    Unreadable { path: PathBuf, reason: String },
    Done,
}
/// Index the store synchronously. Each event goes to `sink`.
pub fn run(projects: &Path, cache: &Path, sink: &(dyn Fn(IndexEvent) + Sync));
/// Run `run` on a background thread.
pub fn spawn(projects: PathBuf, cache: PathBuf) -> std::sync::mpsc::Receiver<IndexEvent>;
```

- A session is a regular file (not a symlink: use `symlink_metadata`) whose
  name gives a `SessionId::from_file_name`, directly inside a directory directly
  inside `projects`. Deeper files (subagent transcripts) are skipped.
- One cache file for each project folder: `<cache>/<hex>.json`, where `<hex>` is
  the first 32 hex digits of the blake3 hash of the folder name. The file holds
  `{ "version": CACHE_VERSION, "folder": "<name>", "entries": [{ "file": "<uuid>.jsonl", "size": u64, "mtime_ns": u64 (nanoseconds since the epoch), "session": Session }] }`.
  A file with another version, another folder, or that does not parse counts
  as empty.
- An entry is a hit when the file name, the size, and the mtime are equal. A
  hit does not open the transcript.
- A folder whose set of entries changed gets a new cache file: write a
  temporary file in the cache directory, named with the pid, a nanosecond
  timestamp, and a counter, with mode 0600, then rename it over the cache file.
- The cache directory gets mode 0700 (create it so, and set the mode when it
  exists).
- A cache file of a folder that no longer exists is removed. A temporary file
  of chf that is older than 10 minutes is removed.
- Folders run in parallel with rayon, newest folder first (by the newest mtime
  of its sessions). Each folder writes its cache file as soon as it is done, so
  a run that stops early keeps the folders that it finished.

### `query` — the words and the first match

```rust
pub struct Query { /* words, each with its compiled Regex */ }
pub struct Match { pub message: usize, pub range: Range<usize> } // byte range in message_text(message)
pub enum Found { Any /* empty query */, At(Match) }
impl Query {
    pub fn parse(text: &str) -> Self;        // words split on whitespace
    pub fn is_empty(&self) -> bool;
    /// None: the session does not hold each word.
    pub fn find(&self, session: &Session) -> Option<Found>;
    /// Each occurrence of each word in `text`, sorted, overlaps merged. For the highlight.
    pub fn ranges_in(&self, text: &str) -> Vec<Range<usize>>;
}
```

- A word is literal (`regex::escape`). A word that holds an uppercase character
  (`char::is_uppercase`) matches its exact case. Each other word matches each
  case with Unicode simple case folding (`RegexBuilder::case_insensitive`).
  The rule applies to each word separately.
- `find` gives the earliest occurrence of any word, in message order.

### `search` — the background search

```rust
pub struct Hit { pub session: usize /* index in the catalog */, pub found: Found }
pub struct Job { pub generation: u64, pub query: Arc<Query>, pub sessions: Vec<(usize, Arc<Session>)> }
pub struct Hits { pub generation: u64, pub hits: Vec<Hit> }
/// None when `latest` moved past `job.generation` before the job was done.
pub fn run_job(job: &Job, latest: &AtomicU64) -> Option<Hits>;
pub struct Searcher { /* sender of jobs, receiver of hits, the latest generation */ }
impl Searcher {
    pub fn spawn() -> Self;
    pub fn submit(&self, job: Job);            // stores job.generation as the latest
    pub fn try_recv(&self) -> Option<Hits>;
}
```

The worker drops a queued job whose generation is stale. `run_job` uses rayon
and does a check of `latest` for each session. The worker runs each job on a
rayon pool of its own. The index fills the global pool, and rayon starts a job
from outside a pool only when the threads of that pool have no other work.

### `app` — the state machine with no terminal access

```rust
pub enum Version { Compacted /* ch: crap --here */, Expanded /* che: crap --here --expand */ }
pub enum Mode { List, Ask { choice: Version } }
pub enum Effect { Search(Job), Quit, Launch { id: SessionId, version: Version } }
pub struct Progress { pub read: usize, pub total: Option<usize>, pub done: bool, pub unreadable: usize }
pub struct Drawn { pub list_rows: u16, pub preview_scroll: i64 }
impl App {
    pub fn new() -> Self;
    pub fn on_key(&mut self, key: KeyEvent) -> Vec<Effect>;
    pub fn on_index(&mut self, events: Vec<IndexEvent>) -> Vec<Effect>;
    pub fn on_hits(&mut self, hits: Hits);
    pub fn on_drawn(&mut self, drawn: Drawn);
    // Read access for render: query_text, query, hits, session(i), sessions_len,
    // selected, list_offset, mode, progress, preview_scroll.
}
```

- `Version` lives in `app`, and `launch` takes it.
- The catalog is a `Vec<Arc<Session>>` in arrival order. Each `Hit` names its
  index there.
- A change of the query adds 1 to the generation and gives a `Search` job over
  the whole catalog. New sessions give a `Search` job over only the new ones,
  with the current generation.
- `on_hits` drops hits of an old generation. The first hits of a new generation
  replace the list. Later hits of the same generation merge into it. The list
  is sorted by `last_activity`, newest first, then by id.
- A selection that the person did not move stays on row 0, the newest session.
  After the person moves the selection, it follows its session id when the list
  changes. When that session leaves the list, the selection keeps its row
  number, clamped, and then follows the session now in that row.
- Keys (`KeyEventKind::Release` is ignored):
  - List: a printable character adds to the query. Backspace removes the last
    character. `Ctrl-U` clears the query. Up and `Ctrl-P` move the selection
    up, Down and `Ctrl-N` move it down. PageUp and PageDown move it by
    `list_rows`. Shift-Up and Shift-Down scroll the preview by one line. A move
    of the selection, a change of the query, or a change of the session in the
    selected row sets the preview scroll to 0.
    Enter on a session that is not compacted gives `Launch { Compacted }`.
    Enter on a compacted session gives `Mode::Ask { choice: Compacted }`.
    Enter on an empty list does nothing. Esc and `Ctrl-C` give `Quit`.
  - Ask: `c` gives `Launch { Compacted }`, `e` gives `Launch { Expanded }`. Up
    and Down change the choice. Enter launches the choice. Esc returns to
    `Mode::List` with the query and the selection unchanged. `Ctrl-C` gives
    `Quit`.

### `excerpt` — the preview lines

```rust
pub enum Tone { Text, Highlight, Author, Compaction, Muted }
pub struct Piece { pub text: String, pub tone: Tone }
pub struct PreviewLine(pub Vec<Piece>);
pub struct Preview { pub lines: Vec<PreviewLine>, pub scroll: i64 /* clamped */ }
pub fn preview(session: &Session, query: &Query, found: &Found, width: u16, height: u16, scroll: i64) -> Preview;
```

- Each message starts with an author line (`Tone::Author`): `user` or
  `assistant`. A compaction point gives a line in `Tone::Compaction` that says
  `compaction` and the token count when it is known.
- The text wraps at `width` display columns (`unicode-width`). The cut is only
  at character boundaries. A wide character never straddles the edge. A tab
  becomes spaces, and each other control character becomes `U+FFFD`.
- Each range of `Query::ranges_in` is `Tone::Highlight`.
- `Found::At`: the view starts 3 lines before the line that holds the start of
  the match. `Found::Any`: the view ends at the last line of the session.
- `scroll` moves the view by lines from that start, and is clamped to the first
  and the last line of the session. Only the messages that the view needs are
  wrapped.

### `render` — draw the state with ratatui

`pub fn draw<Tz: TimeZone>(frame: &mut Frame, app: &App, ctx: &Context<'_, Tz>) -> Drawn`,
with `Context { home: Option<&Path>, tz: &Tz }`.

- Top line: the prompt `> ` and the query. Second line: the status:
  `<matches>/<sessions>`, then `indexing <read>/<total>` until `Done`, then
  `<n> unreadable` when n > 0.
- A width of 100 columns or more puts the list left and the preview right,
  half each. A smaller width puts the list above the preview.
- A row: the local date and time of the last activity (`%Y-%m-%d %H:%M`), the
  compaction mark (`⇊` and the count, `⇊` alone for a count of 0, blank when
  not compacted), the directory with `home` shown as `~`, and the title. Cut
  each field with `textfit`.
- The preview header: the session id, the directory, and the git branch.
- `Mode::Ask` draws a box over the list with the count of compactions, the token
  count before the last compaction (or a sentence that it is not known), a
  sentence when the first match comes before the last compaction, the two
  choices `ch` (compacted) and `che` (expanded) with the highlight on the
  choice, and the keys.
- A footer line names the keys.

### `launch` — the shell command

```rust
pub enum Shell { Bash, Zsh }
/// The base name of $SHELL: bash or zsh. Each other value, or no value, gives None.
pub fn shell_of(value: Option<&OsStr>) -> Option<Shell>;

pub fn script(id: &SessionId, version: Version) -> String;

pub fn paste_command(id: &SessionId, version: Version) -> String;
/// Replace the process with `<shell> -ic <script>`. Gives back only the error of a failed exec.
pub fn exec(shell_path: &Path, script: &str) -> std::io::Error;
```

The script:

```sh
if ! typeset -f crap >/dev/null 2>&1; then
  printf '%s\n' "chf: the crap shell function is not defined in this shell." "Run: crap --shell-setup" "Then open a new shell and run chf again." >&2
  exit 1
fi
crap --here 'uuid'            # or: crap --here --expand 'uuid'
```

The id goes through `shellquote::shell_quote`.

### `main` — the binary

- `clap` with `version = buildinfo::version_string!()` and no other argument.
- Standard input or standard output is not a terminal: print
  `chf: standard input and standard output must be a terminal. chf draws a full-screen picker.`
  to stderr and exit 2.
- No home directory: print an error and exit 2.
- `projects = claude_transcript::projects_dir(home)`, `cache = dirs::cache_dir()/chf`.
- Start `index::spawn` and `Searcher::spawn`, then `ratatui::init()`. The loop
  polls a key for 50 ms, gives the index events and the hits to the app, runs
  each effect, and draws.
- `Quit`: `ratatui::restore()`, exit 130.
- `Launch`: `ratatui::restore()`. If `shell_of($SHELL)` is None, print that
  `$SHELL` is not bash or zsh, print the `paste_command`, and exit 1. Else
  `exec`, and when it returns, print its error and exit 1.
